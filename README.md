## 🌟 Key Features

- **📱 Interactive Mobile Simulator**: Realistic hardware frames showing live store screenshots and interactive UI mockups for shipped apps.
- **🏛 Clean Architecture Visualizer**: Interactive breakdown of Presentation (BLoC/Cubit), Domain (UseCases/Entities), and Data (Dio/Hive) layers.
- **👨‍🏫 Mentorship & Judging Gallery**: Interactive photo gallery featuring hackathon judging, student 1st place victories, and CIC bootcamp training.
- **📊 Impact Metrics Bar**: Highlighting 99.9% crash-free stability rate and 4+ years of cross-platform engineering.
- **⚡ Dark Mode Aesthetic**: Designed with Tailwind CSS, Framer Motion, and glassmorphism UI principles.
